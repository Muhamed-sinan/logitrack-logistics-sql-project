# LogiTrack – Logistics Data Analysis Using SQL

A MySQL project for logistics and shipment data analysis using advanced SQL.


## 📌 Project Overview
LogiTrack is a logistics and shipment management project developed using MySQL. This project analyzes shipment operations, delivery performance, shipping costs, hub efficiency, and delivery delays.

## 🎯 Project Objectives
- Analyze shipment data and delivery status.
- Calculate customer-wise total shipping costs.
- Identify delayed shipments and penalties.
- Evaluate delivery agent performance.
- Analyze hub-wise shipment activity.
- Calculate monthly shipment growth.

## 🛠️ Technologies Used
- MySQL
- SQL
- MySQL Workbench

## 📚 SQL Concepts Used
- Joins and Subqueries
- Aggregate Functions and GROUP BY
- Views
- Stored Procedures
- Triggers
- Transactions and Savepoints
- Common Table Expressions (CTEs)
- Window Functions
- Ranking and Data Analysis

## 📊 Key Analysis
- Hub-wise shipment counts
- Customer-wise total shipping costs
- Delay percentage by hub
- Delivery agent performance
- Month-over-month shipment growth
- Customers who have never received penalties
- Hubs with no delayed shipments

## 🚀 How to Run
1. Clone or download this repository.
2. Open MySQL Workbench.
3. Select the `logitrack_project` database or create the database and tables required by the SQL script.
4. Open the `.sql` file.
5. Execute the SQL statements in the correct order.
6. Review the query results.
